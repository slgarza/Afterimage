# Ten-agent Modal pilot — 2026-11-10

Ten independent Codex processes ran in ten Modal VMs against the same Afterimage
commit. Every worker produced a patch and passed its checks. All ten reviewed
deliveries were merged into GitHub with passing CI: nine without coordinator code
repair and one with a documented accessibility repair.

The workflow is: **GitHub base → ten Modal workers → local review and combined
checks → GitHub PR checks and merge → updated local checkout**. Each worker had
one task and an isolated copy of the repository. The coordinator built the
controller, defined contracts, reviewed changes and integrated them sequentially.
These coordinator activities are separate from the ten cloud workers.

## Budget and cleanup

The authorized pilot budget was USD25: USD18 allocated to model admission and
USD7 reserved for infrastructure. Two probes reserved USD0.50 each; the cohort
reserved USD17. The gateway's conservative model accounting ceiling was
USD5.367561 for the cohort and USD5.422174 including the probes. This charges
cached inputs conservatively and is **not a reconciled OpenAI invoice**.

An upper estimate for VM CPU and memory over the recorded worker/probe lifetimes
is USD0.114351. It excludes gateway functions, image builds, network, storage and
other charges. Total provider billing and total cost per merged PR remain
unverified; no total-spend claim is inferred from this compute-only estimate.
Prior allocations remain in the durable ledger and are not reset or refunded.

All ten worker sandboxes and both probe sandboxes were terminated. The gateway
runs were stopped, with no model requests in flight, and the gateway application
was stopped with zero tasks at the final cleanup check. No paid workers remain
running for this pilot.

## Evidence limits and next stage

Modal can deliver several event lines in one output chunk. The original logger
missed some receipt timestamps, including first command completions. Concurrency
proof uses only timestamped later commands; historical logs were not rewritten.
The logging fix now buffers complete lines before redaction and timestamping.
Process/session overlap does not prove uninterrupted useful computation.

Ownership was disjoint. This run did not exercise simultaneous edits to the same
file, conflict resolution, a 25/50/100-agent cohort or an AFK comparison. It is
not yet a qualifying 100-agent prize submission. The slowest part of delivery
was serial review/integration and CI, which must improve before scaling.

The next stage needs at least 25 useful reviewed tickets, dependency-aware
scheduling, an explicit cumulative budget, and measured integration capacity.
Compare the same initial commit, backlog and acceptance criteria against an AFK
pipeline before claiming an efficiency advantage. Keep raw logs and credentials
private; the JSON report contains only sanitized aggregates and delivery hashes.
